## Research interest

This proposed project focuses on mammographic image analysis, using image-processing and machine-learning methods to investigate suspicious findings. Patient-information fusion would be an optional comparison if suitable data is available.

My main interest is whether combining image features with available patient information, such as age, breast density, and relevant medical history, can improve performance compared with using images alone. I would also like to examine how consistently the model performs across different patient groups.

## Current status

This repository contains the thesis application proposal. The precise prediction task, dataset, and final scope will be agreed with the supervisor before implementation. The intended outcome is an academic research prototype.
